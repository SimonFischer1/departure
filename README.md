# Departure – Simon

Mobile-first Reisewebsite für GitHub Pages.

## Enthalten
- index.html
- style.css
- script.js
- pic/cover.jpeg
- pic/adventure.jpg

## Reise-Daten
Die Daten stehen ganz oben in `script.js`:
- Abreise: 03.09.2026
- Boarding: 05.09.2026
- voraussichtliches Ende: 04.12.2026

## Automatische Tagesansicht
Beim Öffnen wird das aktuelle Datum des Geräts verwendet. Die Datumsleiste und Timeline springen automatisch zum heutigen Tag.

## Bilder austauschen
Einfach:
- `pic/cover.jpeg` für das große Schiffbild
- `pic/adventure.jpg` für das untere Bild

durch eigene Bilder mit denselben Dateinamen ersetzen.

## GitHub Pages
Den Inhalt des ZIPs in dein Repository `departure` kopieren/pushen. `index.html` ist die Startseite.
